# Assets

- `floorplan-bleuplan.png`: the agent's floorplan (Bleuplan), marked
  *not to scale*. Cropped per floor and used as the underlay in the seed
  project. Measured scale: 12.18 mm per image pixel.
- `brochure.pdf`: the sales brochure (also handy for testing PDF import).
- `photos/`: listing photos, named by room. Useful for checking radiators,
  windows and the chimney breasts. Not used by the app yet.
